Chef’s Menu Manager 

About

Chef’s Menu Manager is a React Native mobile application originally developed for POE Part 2. This repository contains the updated version for POE Part 3, with additional features and improvements to the original application.

Part 3 Updates

* Edit, update and delete menu items.
* Search dishes by name.
* Filter dishes by course.
* Display menu statistics.
* Improved interface and user experience.
* Better input validation and code organisation.

Technologies

* React Native
* Expo
* JavaScript / TypeScript

Installation

npm install
npx expo start

Note: This is an enhanced version of the original Chef’s Menu Manager submitted for POE Part 2, not a completely new application.
